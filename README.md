# VideoMaker IA — A sua máquina de edição

Este repositório guarda **somente os arquivos das atualizações automáticas** do VideoMaker IA: o arquivo de versão assinado e as atualizações pequenas, que só funcionam num app já instalado.

O instalador não fica disponível para download público.

## Atualizações
Depois de instalado, o app procura versões novas sozinho, baixa em segundo plano e instala quando você fecha o programa. Cada atualização é **assinada digitalmente** e verificada antes de instalar.
