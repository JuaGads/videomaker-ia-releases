# VideoMaker IA — A sua máquina de edição

Editor de vídeo automático para **Instagram Reels, TikTok e YouTube Shorts**. Roda **100% no seu PC**, sem custo por vídeo.

Este repositório contém **somente os instaladores** e o arquivo de versão usado pelas **atualizações automáticas**.

## Como instalar
1. Abra a página [**Releases**](https://github.com/JuaGads/videomaker-ia-releases/releases/latest) e baixe `VideoMakerIA-Setup-<versão>.exe`.
2. Dê dois cliques no arquivo. Se o Windows mostrar o aviso azul do SmartScreen, clique em **Mais informações → Executar assim mesmo**.
3. Pronto: o atalho **VideoMaker IA** aparece na área de trabalho e no menu Iniciar.

Requisitos: Windows 10/11 64 bits. Placa NVIDIA é opcional (deixa a exportação mais rápida).

## Atualizações
Depois de instalado, o app procura versões novas sozinho, baixa em segundo plano e instala quando você fecha o programa. Cada atualização é **assinada digitalmente** e verificada antes de instalar.
